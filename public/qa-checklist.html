1. CRITICAL PATH — Auth

Registration

  • Register new account with email & password
  • Password under 6 chars is rejected
  • Duplicate email is rejected
  • After registration, lands on onboarding (if first login) then dashboard
  • Stripe redirect: ?paid=true or ?success=true shows register form

Login

  • Log out, then log back in with same credentials
  • Wrong password shows error message
  • Non-existent email shows error message
  • Page refresh keeps you logged in (session persists)
  • Legacy password migration: old SHA-256 user auto-migrates to Supabase Auth on login

Password Reset

  • Click "Forgot Password", enter email
  • Reset email arrives (from Supabase, links to uc30.com?recovery=true)
  • Click link, password reset form appears
  • Set new password successfully
  • Log in with new password

Admin Access

  • Register with admin@uc30.com — gets admin dashboard
  • Non-admin user cannot see admin dashboard
  • Admin-promoted user (via toggle) sees admin dashboard on next login
